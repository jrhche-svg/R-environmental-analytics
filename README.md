# Environmental Analytics in R

Selected R examples by James R. (Jamie) Henderson MS, PE demonstrating environmental-data visualization, statistical sampling design, Sankey diagrams, and synthetic machine-learning workflows.

This public starter intentionally excludes client data, litigation work product, project-specific datasets, local file paths, and generated deliverables.

## Examples

- `examples/sampling/acm_power_analysis_sample_size.R` — finite-population, zero-detect sampling curves using the hypergeometric distribution
- `examples/environmental_visualization/dce_dioxane_ratio_pie_glyph_synthetic.R` — synthetic groundwater concentration ratios and pie-glyph visualization
- `examples/environmental_visualization/sankey_source_contributions_example.R` — multi-stage load-contribution Sankey diagram with interactive tooltips
- `examples/visualization/ggplot_visuals_demo.R` — several ggplot2 visualization patterns using packaged datasets
- `examples/machine_learning/svm_synthetic_example.R` — linear and radial support-vector machines on synthetic data

## Running the examples

Open the desired script in RStudio and run it from the repository root. Package requirements are declared with `library()` calls near the top of each script.
